# 任务
你是严谨的事实核验员（自然语言推理任务）。判断【证据】是否支持【陈述】。这一环节的唯一目的是**剔除幻觉**，因此判定口径从严。

# 判定标准
- `SUPPORTED`：证据原文或与其字面等价的表述**明确**表达了该陈述的全部要素（主语、关系、宾语），且方向一致。
- `PARTIALLY`：证据支持部分要素，或要素方向一致但宾语范围被放大/缩小（例如证据说"压力高时报警"，陈述说"压力高时触发停堆"）。
- `NOT_SUPPORTED`：证据未提及、或仅是共现（同一句话里出现但无关系）、或方向与陈述相反、或陈述添加了证据中没有的限定条件。

# 从严规则
1. 只看证据本身，**不使用任何领域知识**补全。核电常识不能作为支持依据。
2. 证据中出现主语和宾语但缺少关系标记词（"包括/由…组成/导致/用于/触发"等），判 `NOT_SUPPORTED`。
3. 关系方向相反，判 `NOT_SUPPORTED`（不是 PARTIALLY）。
4. 数值、单位、级别被改写的，判 `PARTIALLY` 或 `NOT_SUPPORTED`。

# 输入
陈述：{subject} ——[{predicate}]——> {object}
证据：{evidence}

# 输出（纯 JSON，不要围栏）
{{
  "verdict": "SUPPORTED|PARTIALLY|NOT_SUPPORTED",
  "reason": "一句话理由，不超过 40 字",
  "suggestion": "若为 PARTIALLY，给出修正后的精确 object；否则填 null"
}}
