# 抽取规则（逐条遵守）
1. **实体名使用规范全称**：首次出现时保留缩写标注，例如 `蒸汽发生器（SG）`；后续出现的同一实体统一用规范全称。
2. **只抽取文本明确陈述的事实**，不做领域推断、不做常识补全。文中没有写出的关系一律不抽。
3. **每条三元组必须给出 evidence**：从原文逐字摘录的最小支持片段（10~120 字，标点符号照抄），不得改写。
4. **方向严格**：主语/宾语位置由关系定义决定，例如 `MONITORS` 永远是「参数」在前、「被监测对象」在后。
5. **修饰语保留**：集中在条件型的三元组里把条件写进主语或宾语，例如 `（一回路压力高于SG二次侧压力）`，不要拆出不完整的三元组。
6. **跨句但同段落的事实可以抽**，跨段落的事实不抽，除非明确指代同一主体且证据在同一段。
7. **不确定就标 low**：宁可在后处理中被剔除，也不要凭语言先验补全关系。
8. 输出**纯 JSON 数组**，不要任何解释性文字、不要 markdown 代码块围栏。

# 置信度判定标准
- `high`：原文含明确的句式标记（"包括/主要由…组成/功能是/原因是/导致/不适用时禁止" 等）且主宾明确。
- `medium`：需合并同段两句话才能判定，或实体类型需要推断。
- `low`：隐含表达、代词指代不明确、单位或数值不清晰。
